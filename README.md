# Day 16 - Load a CSV Dataset

## Internship
AI & ML Internship - Level 1, Day 16

## Objective
To load a CSV dataset using Pandas and display the first five and last five records.

## Tools Used
- Python
- Pandas
- Google Colab

## Dataset
Iris Flower Dataset

Dataset Source: https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv

## Description
This project demonstrates how to load a CSV dataset using the Pandas library in Python. The first five and last five records are displayed using the `head()` and `tail()` methods.

## Implementation
1. Imported the Pandas library.
2. Loaded the Iris dataset using `pd.read_csv()`.
3. Displayed the first five records using `df.head()`.
4. Displayed the last five records using `df.tail()`.
5. Checked the dataset dimensions and missing values.

## Output
- Successfully loaded the Iris dataset.
- Displayed the first five and last five records.
- Verified the dataset dimensions and checked for missing values.
